## 🧪 Hacker News Validation - QA Automation Project

🔗 **Repo:** [https://github.com/FaboDaGreat/qa_automation](https://github.com/FaboDaGreat/qa_automation)

An end‑to‑end Playwright test suite that validates **Hacker News’s `/newest` feed**.

**Key engineering highlights**

* Dynamically collects the first ***N* articles** across paginated results
* Verifies articles are ordered **newest → oldest** using stable invariants
* Guards against duplicate data with set‑based validation
* Validates external article links via HTTP requests
* Uses **soft assertions** to surface all failures in a single run
* Separates data collection, validation, and assertions for maintainability

This project demonstrates how I approach **test code as production code** — readable, defensive, and scalable.
